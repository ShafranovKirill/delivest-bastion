## Сделано

- Главная: подписка удалена только из таблицы; единая версия приложения (server — источник, client — fallback), текущая/доступная без разделения компонентов.
- Плашка «Недоступен» зависит от неуспешной внешней проверки именно сайта. Отсутствие данных агента не скрывает этот сбой. Ошибки API остаются общим состоянием и диагностикой. Плановое выключение сохраняет метку «Выключен».
- Страница: семь независимых закрытых модулей со сводками; контакты, подписка, зашифрованные доступы и все команды сохранены. Старые `?tab=` ссылки раскрывают соответствующий модуль; команды открывают диагностику.
- Бот: основные быстрые действия; убраны rollback/logs/details из новых карточек и кнопка логов из тревог.
- Widgets: личный разрешённый чат, статусы/единая версия/команды, подтверждения, одноразовые токены на 15 минут, повторная проверка разрешённых действий и занятости. Ход команды обновляет состояние виджета. Обычные кнопки — fallback для API/групп/старого клиента.
